# Horizon Europe / CORDIS BI Dashboard - System Overview

## 1. System Goal & Purpose
The **Horizon Europe / CORDIS BI Dashboard** is a Business Intelligence web application designed to visualize, analyze, and compare funding data from the European Union's Horizon Europe framework programme.

Its primary goals are:
*   To provide a clear, interactive overview of project participation and EU contributions.
*   To enable specialized analysis of **Greek participation** (participants, coordinators, beneficiaries).
*   To facilitate **Comparative Analysis** between different entities (e.g., Countries, Sectors, Groups) using a standardized "Comparison Pack" format.
*   To simplify the data aggregation process from raw Horizon Platform Excel exports.

## 2. Core Capabilities & Modules

### A. Dashboard Overview (Σύνοψη)
The main landing page provides high-level KPIs and charts, dynamically adapting to the selected dataset type:
*   **For Project Datasets:**
    *   KPIs: Total Projects, Greek Participation count/%, Greek Coordinator count/%.
    *   Charts: Coordinator Country Rankings, Consortium Composition, Greek Participation breakdown.
    *   Filters: Toggle specific filters like "Greek Participation Only", "Valid Projects Only".
*   **For Comparison Packs (Summary):**
    *   KPIs: Total Participation count, Total EU Contribution (€), Number of Entities/Groups.
    *   Charts: Grouped Bar Charts comparing entities across Pillars, Programmes, and Missions.
    *   Filters: Group/Entity Selector to isolate specific comparison targets.

### B. Analytics (Αναλύσεις)
A deeper dive into the data structure:
*   **For Project Datasets:** Analysis of Top Keywords, Fields of Science (hierarchical), and Investment Priorities.
*   **For Comparison Packs:** Tabbed interface for detailed tables and charts:
    *   **Pillar Analysis:** Participation per Pillar per Entity.
    *   **Programme Analysis:** Participation & EU Contribution per Framework Programme.
    *   **Mission Analysis:** EU Contribution per Mission.

### C. Chart Builder (Δημιουργία Γραφημάτων)
An ad-hoc reporting tool allowing users to:
*   Select Dimensions (X-Axis): e.g., Programme, Pillar, Country, Year.
*   Select Metrics (Y-Axis): e.g., Count, Sum of Budget, Average Cost.
*   Select Chart Type: Bar, Line, Pie, Doughnut, Radar.
*   **Export:** Download charts as high-resolution PNG images for reports.

### D. Converter & Merger (Μετατροπέας / Συγχώνευση) **(NEW)**
A dedicated module to streamline data preparation:
*   **Multi-File Upload:** Accepts raw Excel exports from the Horizon Platform (e.g., "Pillar Participation", "Programme Contribution").
*   **Auto-Detection:** Automatically recognizes file contents based on header columns.
*   **Grouping:** Allows users to define "Entities" (e.g., "Greece", "Germany - SMEs") and assign files to them.
*   **Merging:** Aggregates all input files into a single, standardized **"Comparison Pack"** Excel file (`.xlsx`), handling data summation and deduplication automatically.

### E. Data Management (Διαχείριση Δεδομένων)
*   **Import:** Supports importing two types of datasets:
    1.  **Standard CORDIS Projects:** Raw list of projects (Excel) + Enrichment data (JSONL).
    2.  **Comparison Packs:** The aggregated file generated by the Converter.
*   **Management:** View, Delete, and Switch active datasets.

## 3. Technical Architecture

*   **Backend:** PHP 8.1+ (No heavy framework, custom lightweight router/API).
*   **Database:**
    *   **Dual Driver Support:** SQLite (default/portable) and MySQL (production-ready).
    *   **Schema:** Relational tables for Projects, Participants, and Summary/Aggregation tables.
*   **Frontend:** HTML5, CSS3 (Glassmorphism design), JavaScript (ES6+).
    *   **Visualization:** Chart.js for rendering responsive, interactive charts.
    *   **Interactivity:** jQuery & DataTables for advanced table sorting/filtering.
*   **Infrastructure:**
    *   **Setup Script:** Automated `setup.sh` for Ubuntu/Debian to install Nginx, PHP, MySQL, Composer, and phpMyAdmin.
    *   **Database Management:** Integrated **phpMyAdmin** installation for direct database oversight.

## 4. Key Workflows

1.  **Project Analysis:** User uploads a list of projects -> System identifies Greek participation -> Dashboard shows KPIs -> User builds custom charts.
2.  **Comparative Study:** User downloads 4 Excel files per country from Horizon Dashboard -> Uploads them to "Converter" -> Assigns labels "Greece", "EU Avg" -> Downloads "Comparison Pack" -> Imports to Dashboard -> Views side-by-side comparison charts.
